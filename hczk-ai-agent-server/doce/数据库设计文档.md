# 桓宸智科AI平台 - 数据库设计文档

## 一、概述

本文档描述桓宸智科AI平台的数据库设计，包括表结构、字段定义、索引设计、外键关系及ER图说明。

**数据库类型**：MySQL 8.0（生产环境）/ H2（开发测试环境）
**字符集**：utf8mb4
**排序规则**：utf8mb4_unicode_ci
**存储引擎**：InnoDB

## 三、表结构设计

### 3.1 users（用户表）

**表说明**：存储平台用户信息，包括管理员和普通用户

| 字段名 | 数据类型 | 长度/精度 | 是否为空 | 默认值 | 说明 |
|--------|----------|-----------|----------|--------|------|
| id | BIGINT | - | NOT NULL | AUTO_INCREMENT | 主键 |
| username | VARCHAR | 50 | NOT NULL | - | 用户名，唯一 |
| password | VARCHAR | 255 | NOT NULL | - | BCrypt加密后的密码 |
| email | VARCHAR | 100 | NOT NULL | - | 邮箱地址 |
| phone_number | VARCHAR | 20 | YES | NULL | 手机号 |
| company_name | VARCHAR | 100 | YES | NULL | 公司名称 |
| role | VARCHAR | 20 | NOT NULL | 'USER' | 用户角色：ADMIN/USER |
| balance | DECIMAL | 19,4 | NOT NULL | 0.0000 | 账户余额（元） |
| total_usage_tokens | BIGINT | - | NOT NULL | 0 | 累计消耗token数 |
| status | VARCHAR | 20 | NOT NULL | 'active' | 账户状态：active/inactive |
| created_at | DATETIME | - | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | - | NOT NULL | CURRENT_TIMESTAMP | 更新时间 |

**索引设计**：
```sql
PRIMARY KEY (id),
UNIQUE KEY uk_username (username),
UNIQUE KEY uk_email (email),
KEY idx_role (role),
KEY idx_status (status),
KEY idx_created_at (created_at)
```

---

### 3.2 ai_models（AI模型表）

**表说明**：存储接入的大语言模型配置信息

| 字段名 | 数据类型 | 长度/精度 | 是否为空 | 默认值 | 说明 |
|--------|----------|-----------|----------|--------|------|
| id | BIGINT | - | NOT NULL | AUTO_INCREMENT | 主键 |
| name | VARCHAR | 100 | NOT NULL | - | 模型显示名称 |
| provider | VARCHAR | 100 | NOT NULL | - | 提供商名称 |
| model_id | VARCHAR | 100 | NOT NULL | - | 模型调用ID |
| status | VARCHAR | 20 | NOT NULL | 'ACTIVE' | 状态：ACTIVE/INACTIVE |
| api_base | VARCHAR | 255 | YES | NULL | API基础地址 |
| api_key | VARCHAR | 512 | YES | NULL | 平台API密钥（加密存储） |
| input_price | DECIMAL | 19,6 | YES | NULL | 输入价格（元/1K tokens） |
| output_price | DECIMAL | 19,6 | YES | NULL | 输出价格（元/1K tokens） |
| max_tokens | INT | - | YES | NULL | 最大上下文长度 |
| created_at | DATETIME | - | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | - | NOT NULL | CURRENT_TIMESTAMP | 更新时间 |

**索引设计**：
```sql
PRIMARY KEY (id),
UNIQUE KEY uk_model_id (model_id),
KEY idx_status (status),
KEY idx_provider (provider)
```

---

### 3.3 agents（智能体表）

**表说明**：存储用户创建的AI智能体配置

| 字段名 | 数据类型 | 长度/精度 | 是否为空 | 默认值 | 说明 |
|--------|----------|-----------|----------|--------|------|
| id | BIGINT | - | NOT NULL | AUTO_INCREMENT | 主键 |
| name | VARCHAR | 100 | NOT NULL | - | 智能体名称 |
| description | TEXT | - | YES | NULL | 智能体描述 |
| model_id | BIGINT | - | NOT NULL | - | 关联模型ID（外键） |
| user_id | BIGINT | - | NOT NULL | - | 所属用户ID（外键） |
| status | VARCHAR | 20 | NOT NULL | 'ACTIVE' | 状态：ACTIVE/INACTIVE |
| agent_type | VARCHAR | 50 | YES | NULL | 智能体类型 |
| total_calls | BIGINT | - | NOT NULL | 0 | 累计调用次数 |
| total_tokens | BIGINT | - | NOT NULL | 0 | 累计消耗token数 |
| avg_latency | INT | - | YES | NULL | 平均响应延迟(ms) |
| created_at | DATETIME | - | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | - | NOT NULL | CURRENT_TIMESTAMP | 更新时间 |

**索引设计**：
```sql
PRIMARY KEY (id),
KEY idx_user_id (user_id),
KEY idx_model_id (model_id),
KEY idx_status (status),
KEY idx_agent_type (agent_type),
CONSTRAINT fk_agent_model FOREIGN KEY (model_id) REFERENCES ai_models(id),
CONSTRAINT fk_agent_user FOREIGN KEY (user_id) REFERENCES users(id)
```

### 3.4 api_keys（API密钥表）

**表说明**：存储用户的API调用密钥

| 字段名 | 数据类型 | 长度/精度 | 是否为空 | 默认值 | 说明 |

## 六、性能优化建议

### 6.1 索引优化
- `users` 表的 `username` 和 `email` 已建立唯一索引
- `api_keys` 表的 `api_key` 已建立唯一索引（高频查询）
- `billing_records` 表按 `user_id + created_at` 组合查询频繁，建议建立联合索引
- `agents` 表按 `user_id` 查询频繁，已建立普通索引

### 6.2 分表分库建议（未来扩展）
- `billing_records` 数据量增长快，建议按月分表
- `recharge_records` 可保留热数据（近1年），冷数据归档

### 6.3 缓存策略
- 用户余额信息缓存到Redis，减少数据库查询
- 模型配置信息缓存，启动时加载到内存
- API Key映射关系缓存，提升鉴权效率
