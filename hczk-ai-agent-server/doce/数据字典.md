# 桓宸智科AI平台 - 数据字典

## 一、用户相关

### users（用户表）
| 字段 | 类型 | 含义 | 业务规则 |
|------|------|------|----------|
| username | VARCHAR(50) | 登录账号 | 全局唯一，支持字母/数字/下划线 |
| password | VARCHAR(255) | 登录密码 | BCrypt加密存储，不可逆向解密 |
| email | VARCHAR(100) | 邮箱 | 全局唯一，用于通知和找回密码 |
| phone_number | VARCHAR(20) | 手机号 | 可选，用于短信通知 |
| company_name | VARCHAR(100) | 公司名称 | 可选，企业用户填写 |
| role | VARCHAR(20) | 角色 | ADMIN=超级管理员，USER=普通用户 |
| balance | DECIMAL(19,4) | 账户余额 | 单位：人民币元，精确到分 |
| total_usage_tokens | BIGINT | 累计消耗token | 统计用户所有调用的token总数 |
| status | VARCHAR(20) | 账户状态 | active=正常，inactive=已冻结 |

## 二、模型相关

### ai_models（AI模型表）
| 字段 | 类型 | 含义 | 业务规则 |
|------|------|------|----------|
| name | VARCHAR(100) | 显示名称 | 如"DeepSeek-V3" |
| provider | VARCHAR(100) | 提供商 | 如"百度智能云"、"阿里云" |
| model_id | VARCHAR(100) | 调用标识 | API调用时的model参数值 |
| status | VARCHAR(20) | 服务状态 | ACTIVE=可调用，INACTIVE=已停用 |
| api_base | VARCHAR(255) | 基础地址 | 兼容OpenAI格式的API地址 |
| api_key | VARCHAR(512) | 平台密钥 | 管理员配置的厂商API Key |
| input_price | DECIMAL(19,6) | 输入单价 | 每1000个输入token的价格（元） |
| output_price | DECIMAL(19,6) | 输出单价 | 每1000个输出token的价格（元） |
| max_tokens | INT | 最大上下文 | 模型支持的最大token数 |

**模型定价标准**：
| 模型 | input_price | output_price | 说明 |
|------|-------------|--------------|------|
| DeepSeek-V3 | 0.001 | 0.002 | 性价比最高 |
| ERNIE-4.0-Turbo | 0.008 | 0.008 | 百度旗舰模型 |
| qwen-max | 0.020 | 0.020 | 阿里云旗舰模型 |
| GLM-4-Plus | 0.010 | 0.010 | 智谱长上下文模型 |

## 六、计费相关

### billing_records（计费记录表）
| 字段 | 类型 | 含义 | 业务规则 |
|------|------|------|----------|
| user_id | BIGINT | 用户ID | 关联users.id |
| type | VARCHAR(20) | 记录类型 | TOKEN_USAGE=消耗扣费，RECHARGE=充值 |
| amount | DECIMAL(19,4) | 金额 | 正数=充值，负数=消费 |
| balance_after | DECIMAL(19,4) | 操作后余额 | 记录操作后的账户余额 |
| input_tokens | BIGINT | 输入token | 仅TOKEN_USAGE类型有值 |
| output_tokens | BIGINT | 输出token | 仅TOKEN_USAGE类型有值 |
| detail | VARCHAR(500) | 详情 | 如"DeepSeek-V3调用"、"支付宝充值" |

**计费公式**：
```
费用 = input_tokens / 1000 × input_price + output_tokens / 1000 × output_price
```

**Token 估算规则**（流式响应无法获取精确 usage，采用字符估算）：
- 综合混合文本：约 2 字符 = 1 token
- 估算工具类：`com.hczk.hczkaiagentserver.util.TokenCounter`

**计费流程**：
1. 用户发送消息 → ChatService 估算输入 tokens
2. 模型流式输出完成 → 估算输出 tokens
3. 按模型定价计算费用 → BillingService.deductBalance() 扣减余额
4. 写入 billing_records 记录 + 更新智能体统计

### recharge_records（充值记录表）
| 字段 | 类型 | 含义 | 业务规则 |
|------|------|------|----------|
| user_id | BIGINT | 用户ID | 关联users.id |
| amount | DECIMAL(19,4) | 充值金额 | 用户实际支付的金额 |
| bonus_amount | DECIMAL(19,4) | 赠送金额 | 平台赠送的金额 |
| payment_method | VARCHAR(50) | 支付方式 | alipay=支付宝，wechat=微信支付 |
| transaction_id | VARCHAR(100) | 交易号 | 第三方支付平台的交易流水号 |
| status | VARCHAR(20) | 交易状态 | success=成功，pending=处理中，failed=失败 |

**充值套餐规则**：
| 套餐名 | amount | bonus_amount | 实到账 |
|--------|--------|--------------|--------|
| 入门包 | 100.00 | 0.00 | 100.00 |
| 标准包 | 500.00 | 50.00 | 550.00 |
| 专业包 | 1000.00 | 150.00 | 1150.00 |
| 企业包 | 5000.00 | 1000.00 | 6000.00 |
