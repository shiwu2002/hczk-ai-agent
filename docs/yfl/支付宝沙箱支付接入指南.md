# 支付宝沙箱环境接入指南

## 一、概述

本文档介绍如何在桓宸智科AI平台中接入支付宝沙箱支付，用于用户充值功能。

**适用场景**：开发/测试阶段模拟真实支付宝支付流程，上线前切换为正式环境。

---

## 二、沙箱环境 vs 正式环境

| 对比项 | 沙箱环境 | 正式环境 |
|--------|---------|---------|
| 用途 | 开发测试 | 生产上线 |
| 网关地址 | `https://openapi-sandbox.dl.alipaydev.com/gateway.do` | `https://openapi.alipay.com/gateway.do` |
| APPID | 沙箱专用（自动生成） | 企业认证后申请 |
| 支付方式 | **沙箱钱包App扫码** | 真实支付宝App |
| 签名算法 | RSA2 (SHA256WithRSA) | RSA2 (SHA256WithRSA) |
| 费用 | 免费 | 按交易金额收取服务费 |

---

## 三、接入步骤

### 3.1 注册蚂蚁开放平台账号

1. 访问 [蚂蚁开放平台](https://open.alipay.com/)
2. 使用企业支付宝账号登录（个人可注册开发者账号）
3. 进入「研发服务」→「沙箱环境」

### 3.2 获取沙箱配置信息

登录后在「沙箱应用」页面获取以下信息：

```
APPID:    202100XXXXXXXXXX
网关地址: https://openapi-sandbox.dl.alipaydev.com/gateway.do
```

### 3.3 生成 RSA2 密钥对

```bash
# 安装 OpenSSL 后执行
# 1. 生成私钥（2048位，PKCS8格式）
openssl genrsa -out app_private_key.pem 2048

# 2. 从私钥导出公钥
openssl rsa -in app_private_key.pem -pubout -out app_public_key.pem

# 3. 将公钥上传到沙箱配置页面 → 「设置」→「接口加签方式」
#    上传后平台会返回「支付宝公钥」，保存下来
```

**密钥格式要求**：
- 私钥：PKCS8 格式（Java 默认使用）
- 公钥：从私钥导出，上传到开放平台

### 3.4 配置沙箱账户

在沙箱页面获取测试买家账号：

```
买家账号: xxx@sandbox.com
支付密码: 111111
余额:     99999.00 元
```

> 注意：沙箱支付必须使用沙箱买家账号的 **沙箱钱包 App** 扫码，真实支付宝无法完成沙箱支付。

### 5.3 AlipayServiceImpl.java 实现

```java
package com.hczk.hczkaiagentserver.service.impl;

import com.alipay.api.AlipayApiException;
import com.alipay.api.AlipayClient;
import com.alipay.api.DefaultAlipayClient;
import com.alipay.api.domain.AlipayTradePagePayModel;
import com.alipay.api.internal.util.AlipaySignature;
import com.alipay.api.request.AlipayTradePagePayRequest;
import com.alipay.api.request.AlipayTradeQueryRequest;
import com.alipay.api.response.AlipayTradeQueryResponse;
import com.hczk.hczkaiagentserver.config.AlipayConfig;
import com.hczk.hczkaiagentserver.service.AlipayService;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;

import java.math.BigDecimal;
import java.util.Map;

@Slf4j
@Service
@RequiredArgsConstructor
public class AlipayServiceImpl implements AlipayService {

    private final AlipayConfig alipayConfig;

    /**
     * 创建支付宝客户端实例
     */
    private AlipayClient getAlipayClient() {
        return new DefaultAlipayClient(
            alipayConfig.getGatewayUrl(),
            alipayConfig.getAppId(),
            alipayConfig.getPrivateKey(),
            "json",
            alipayConfig.getCharset(),
            alipayConfig.getAlipayPublicKey(),
            alipayConfig.getSignType()
        );
    }

    @Override
    public String createOrder(Long userId, BigDecimal amount, String orderNo) {
        try {
            AlipayClient client = getAlipayClient();

            // 构建电脑网站支付请求
            AlipayTradePagePayRequest request = new AlipayTradePagePayRequest();
            request.setNotifyUrl(alipayConfig.getNotifyUrl());
            request.setReturnUrl(alipayConfig.getReturnUrl());

            // 设置业务参数
            AlipayTradePagePayModel model = new AlipayTradePagePayModel();
            model.setOutTradeNo(orderNo);                    // 商户订单号
            model.setTotalAmount(amount.setScale(2, java.math.RoundingMode.HALF_UP).toString());
            model.setSubject("桓宸智科AI平台充值");          // 商品标题
            model.setProductCode("FAST_INSTANT_TRADE_PAY");   // 产品码（电脑网站支付固定值）
            model.setBody("用户ID:" + userId + " 充值");       // 商品描述
            request.setBizModel(model);

            // 调用API并返回支付表单HTML
            return client.pageExecute(request).getBody();

        } catch (AlipayApiException e) {
            log.error("创建支付宝订单失败: {}", e.getMessage());
            throw new RuntimeException("创建支付订单失败");
        }
    }

    @Override
    public boolean handleNotify(Map<String, String> params) {
        try {
            // 1. 验证签名（防止伪造回调）
            boolean signVerified = AlipaySignature.rsaCheckV1(
                params,
                alipayConfig.getAlipayPublicKey(),
                alipayConfig.getCharset(),
                alipayConfig.getSignType()
            );

            if (!signVerified) {
                log.warn("支付宝异步通知验签失败");
                return false;
            }

            // 2. 解析支付状态
            String tradeStatus = params.get("trade_status");

            if ("TRADE_SUCCESS".equals(tradeStatus) || "TRADE_FINISHED".equals(tradeStatus)) {
                String outTradeNo = params.get("out_trade_no");   // 商户订单号
                String tradeNo = params.get("trade_no");           // 支付宝交易号
                String totalAmount = params.get("total_amount");   // 实付金额

                log.info("支付宝支付成功: orderNo={}, tradeNo={}, amount={}",
                    outTradeNo, tradeNo, totalAmount);

                // TODO: 在此处调用 billingService 完成充值到账
                // billingService.rechargeByAlipay(outTradeNo, tradeNo, totalAmount);
                return true;
            }

        } catch (AlipayApiException e) {
            log.error("处理支付宝通知异常: {}", e.getMessage());
        }
        return false;
    }

    @Override
    public boolean queryOrderStatus(String orderNo) {
        try {
            AlipayClient client = getAlipayClient();
            AlipayTradeQueryRequest request = new AlipayTradeQueryRequest();
            request.setBizContent("{\"out_trade_no\":\"" + orderNo + "\"}");

            AlipayTradeQueryResponse response = client.execute(request);
            if (response.isSuccess()) {
                String tradeStatus = response.getTradeStatus();
                return "TRADE_SUCCESS".equals(tradeStatus)
                    || "TRADE_FINISHED".equals(tradeStatus);
            }
        } catch (AlipayApiException e) {
            log.error("查询支付宝订单失败: {}", e.getMessage());
        }
        return false;
    }
}
```

### 5.4 扩展 BillingController.java

```java
// ========== 支付宝充值相关接口 ==========

@Autowired
private AlipayService alipayService;

/**
 * 发起支付宝充值
 * POST /api/billing/recharge-alipay
 * Body: { "amount": 10.00 }
 *
 * 返回支付表单HTML，前端直接渲染即可弹出支付二维码
 */
@PostMapping("/recharge-alipay")
public ResponseEntity<?> createAlipayRecharge(
        @RequestBody Map<String, Object> body,
        Authentication auth) {
    Long userId = resolveUserId(auth);
    BigDecimal amount = new BigDecimal(body.get("amount").toString());

    if (amount.compareTo(new BigDecimal("0.01")) < 0) {
        return ResponseEntity.badRequest().body(Map.of("error", "最低充值金额为0.01元"));
    }

    // 生成唯一订单号
    String orderNo = "RCH-" + System.currentTimeMillis() + "-" + userId;

    // TODO: 先创建待支付的充值记录
    // rechargeRecordService.createPendingRecord(userId, amount, orderNo);

    // 创建支付宝订单并返回支付表单
    String payFormHtml = alipayService.createOrder(userId, amount, orderNo);

    return ResponseEntity.ok(Map.of(
        "orderNo", orderNo,
        "payForm", payFormHtml,
        "message", "请在弹窗中完成支付"
    ));
}

/**
 * 支付宝异步通知回调（服务器端，非浏览器调用）
 * POST /api/billing/alipay/notify
 * 支付宝服务器会POST此地址通知支付结果
 */
@PostMapping("/alipay/notify")
public String alipayNotify(HttpServletRequest request) {
    Map<String, String> params = new HashMap<>();
    request.getParameterMap().forEach((key, values) ->
        params.put(key, values[0])
    );

    boolean success = alipayService.handleNotify(params);
    return success ? "success" : "failure";
}

/**
 * 查询充值结果
 * GET /api/billing/recharge/{orderNo}/status
 */
@GetMapping("/recharge/{orderNo}/status")
public ResponseEntity<?> checkRechargeStatus(@PathVariable String orderNo) {
    boolean paid = alipayService.queryOrderStatus(orderNo);
    return ResponseEntity.ok(Map.of("orderNo", orderNo, "paid", paid));
}
```

## 八、沙箱测试步骤

### 8.1 准备工作

1. 确保后端启动，`alipay.enabled=true`
2. 确保 `notifyUrl` 可被支付宝服务器访问（本地开发用 ngrok 内网穿透）

```bash
# 安装 ngrok 并暴露本地端口
ngrok http 8080
# 输出类似: https://xxxx.ngrok.io -> http://localhost:8080
# 将 notifyUrl 设为: https://xxxx.ngrok.io/api/billing/alipay/notify
```

### 8.2 测试流程

1. 前端发起充值 → 后端返回支付表单
2. 打开 **支付宝沙箱钱包 App**（不是真支付宝！）
   - 沙箱钱包下载地址：在沙箱页面点击「沙箱工具」
3. 用沙箱钱包扫描页面上的二维码
4. 输入支付密码 `111111`
5. 确认支付
6. 后端收到异步通知 → 更新余额
7. 前端轮询检测到支付成功 → 提示用户

### 8.3 沙箱常见问题

| 问题 | 解决方案 |
|------|---------|
| 真支付宝扫码无反应 | 必须用沙箱钱包App扫码 |
| 验签失败 | 检查公钥是否正确上传到开放平台 |
| notifyUrl 收不到回调 | 本地开发需用 ngrok/frp 内网穿透 |
| 余额不足 | 沙箱买家默认99999元，足够测试 |

## 九、上线切换清单

从沙箱切换到正式环境只需修改配置：

```yaml
alipay:

  app-id: ${ALIPAY_APP_ID:正式APPID}
  gateway-url: https://openapi.alipay.com/gateway.do
  private-key: |
    （正式应用私钥）
  alipay-public-key: |
    （正式支付宝公钥）
  notify-url: https://生产域名/api/billing/alipay/notify
  return-url: https://生产前端域名/recharge/result
```

**切换检查项**：

- [ ] 替换 APPID 为正式应用ID
- [ ] 替换网关地址为正式环境
- [ ] 替换密钥对为正式应用的密钥
- [ ] 修改 notifyUrl/returnUrl 为生产域名
- [ ] 确保生产域名的 HTTPS 证书有效
- [ ] 在正式环境中完成一笔小额测试（0.01元）

## 十、安全注意事项

1. **异步通知必须验签**：所有 `/alipay/notify` 回调必须验证签名
2. **金额以通知为准**：不能信任前端传入的金额，以支付宝回调为准
3. **防重复到账**：用商户订单号做幂等校验，同一笔订单只处理一次
4. **HTTPS 必须**：正式环境 notifyUrl 必须是 HTTPS
5. **私钥安全**：应用私钥不要提交到 Git，使用环境变量注入
